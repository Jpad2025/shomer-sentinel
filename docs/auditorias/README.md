# Auditorías técnicas

Informes de investigación de un momento específico — hallazgos con fecha,
verificados contra el código de ese día. No son la referencia final del
sistema (eso es `CLAUDE.md`); son el detalle de cómo se llegó a cada decisión.

Nada se borra de aquí sin releerlo primero: algunos ítems marcados "pendiente"
en su fecha original ya se resolvieron después — verificar contra `CLAUDE.md`
antes de retomar cualquiera de estos hallazgos como si siguiera abierto.
